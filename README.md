# Company Data API ETL & PostgreSQL Analytics + Next.js App

Проект для извлечения, дедупликации и загрузки данных о компаниях из неструктурированной выгрузки внутреннего API (~1000 записей, 20 JSON-файлов + CSV-догрузка) в СУБД PostgreSQL с автоматическим созданием схемы, индексов, аналитическими SQL-запросами, обработкой аномалий и веб-интерфейсом на **Next.js (App Router)**.

## Задача 1: База данных PostgreSQL и ETL

### Дедупликация
В процессе анализа входных данных выявлено 1000 записей и 994 уникальных `id` (6 дублирующихся строк: `c_000224`, `c_000254`, `c_000263`, `c_000285`, `c_000367`, `c_000453`).
Дедупликация реализована на уровне СУБД с помощью `PRIMARY KEY (id)` и инструкции `ON CONFLICT (id) DO NOTHING`.

### Индексы (`schema.sql`)
1. **`idx_companies_category`** — оптимизирует группировку по категориям.
2. **`idx_companies_city_reviews_rating`** — составной индекс для агрегации рейтинга по городам с фильтрацией `reviews_count >= 10`.
3. **`idx_companies_site`** — частичный индекс (`WHERE site IS NOT NULL`) для быстрой оценки доли компаний с сайтом.

## Задача 2: Веб-страница на Next.js (App Router)

Маршрут `/companies` предоставляет веб-интерфейс в тёмном стиле (Linear / Dark Tech design language) для просмотра компаний с возможностью поиска по названию и фильтрации по городу.

- **Серверный рендеринг**: Данные выбираются напрямую из PostgreSQL в Server Component (`src/app/companies/page.tsx`) и Route Handler (`src/app/api/companies/route.ts`).
- **Секреты**: В репозитории отсутствуют секретные данные. Подключение настраивается через файл `.env` (образец предоставлен в `.env.example`).

## Задача 3: Анализ аномалий review.csv

При анализе файла `review.csv` выявлен ряд критических аномалий (подробный документ — [`ANOMALIES.md`](file:///c:/Users/pvppv/Desktop/roo/task/ANOMALIES.md)):

1. **Несоответствие сущностей**: Файл называется `review.csv`, но не содержит отзывов (текста, дат, авторов), а содержит сущности **компаний**.
2. **Аномалии в ID**: Пустые строки 207-208, аномальные номера `c_900006`…`c_900011`, дубликаты (`c_001049`, `c_001050`, `c_001075`) и пересечения с JSON-базой.
3. **Ошибки типов данных**: Запятая в рейтинге (`'4,5'`), невалидный диапазон (`-3.0`, `7.2`), отрицательный счетчик отзывов (`-10`), дробный отзыв (`45.5`), опечатки в протоколах (`htp://`) и поврежденные номера телефонов (`8 (925) abc-12-34`).

Скрипт [`load_review.py`](file:///c:/Users/pvppv/Desktop/roo/task/load_review.py) производит санитизацию этих данных и безопасное обновление/догрузку 196 новых валидных записей в PostgreSQL.

## Инструкция по запуску

### 1. Клонирование репозитория
```bash
git clone https://github.com/ArtemChik103/polza-agency-test.git
cd polza-agency-test
```

### 2. Запуск контейнера PostgreSQL
```bash
docker compose up -d
```

### 3. Загрузка основных данных и CSV-догрузки (ETL)
```bash
pip install -r requirements.txt
python load_data.py
python load_review.py
```

### 4. Настройка .env и запуск Next.js приложения
```bash
cp .env.example .env
npm install
npm run dev
```

Откройте [http://localhost:3000/companies](http://localhost:3000/companies) в браузере.
