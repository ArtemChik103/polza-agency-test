# Отчёт об аномалиях в файле review.csv (Задача 3)

В процессе первичного исследования и автоматизированного аудита файла `review.csv` из архива `data_pack.zip` были выявлены концептуальные, структурные и форматные аномалии.

---

## 🚨 1. Несоответствие назначения и структуры файла (Conceptual Mismatch)

* **Название файла:** `review.csv` (предполагает наличие отзывов пользователей: `review_id`, `user_id`, `text`, `created_at`, `rating`).
* **Фактическое содержимое:** Набор данных сущностей компаний со столбцами: `id, name, category, city, address, rating, reviews_count, site, phone`.
* **Как обнаружено:** Автоматическим скриптом проверки схемы файлов через Pandas и инспекцией первых байтов файла. Файл не содержит текстов отзывов или связывающих ключей, а является дополнительной выгрузкой организаций.

---

## 🆔 2. Аномалии идентификаторов (ID Anomalies)

1. **Пустые строки в конце файла (NULL IDs):**
   * **Где:** Строки 207 и 208 (индексы 205 и 206 CSV-файла).
   * **В чём суть:** Строки состоят исключительно из запятых и не содержат ни одного поля (`id`, `name` и остальные поля равны `NULL`).
   * **Как обнаружено:** Поиском `NaN` значений в ключевом столбце `id`.

2. **Аномальная нумерация ID (Out-of-bounds IDs):**
   * **Где:** Записи с ID `c_900006`, `c_900007`, `c_900008`, `c_900009`, `c_900010`, `c_900011`.
   * **В чём суть:** Основной диапазон нумерации в базе данных составляет `c_000001` … `c_001200`. Данные 6 записей имеют искусственно завышенные номера `c_900000+`.
   * **Как обнаружено:** Диапазонным анализом чисел после префикса `c_`.

3. **Пересечение первичных ключей с основной базой (Cross-DB Overlap):**
   * **Где:** 6 ID: `c_000098`, `c_000246`, `c_000263`, `c_000425`, `c_000769`, `c_000851`.
   * **В чём суть:** Эти ID уже содержались в основных JSON-файлах (`page_001.json` ... `page_020.json`). Данные полностью дублируют существующие записи.
   * **Как обнаружено:** Операцией пересечения множеств `set(json_ids).intersection(set(csv_ids))`.

4. **Внутренние дубликаты ID внутри review.csv (Internal Duplicates):**
   * **Где:** 3 паритетные пары записей:
     * `c_001049` («Ритм Сервис», г. Волгоград) — строки 40 и 202;
     * `c_001050` (ООО «Кварц Тех», г. Москва) — строки 115 и 203;
     * `c_001075` (ООО «Восток Групп», г. Уфа) — строки 5 и 204.
   * **Как обнаружено:** Группировкой и фильтрацией `csv_df[csv_df.duplicated(subset=['id'])]`.

## 📐 3. Аномалии типов данных и формата (Data Format Anomalies)

1. **Некорректный разделитель десятичных дробей в рейтинге:**
   * **Где:** Строка 14 (`c_001010`, ООО «Инновация»).
   * **В чём суть:** Значение рейтинга записано с запятой: `'4,5'` вместо `'4.5'`.
   * **Как обнаружено:** Попыткой парсинга значений `rating` в тип `float` без предварительной замены запятой.

2. **Значения рейтинга за пределами допустимого диапазона [1.0, 5.0]:**
   * **Где:** 
     * Строка 96 (`c_001122`): `rating = -3.0` (отрицательный рейтинг).
     * Строка 197 (`c_001186`): `rating = 7.2` (завышенный рейтинг при 5-балльной шкале).
   * **Как обнаружено:** Условием валидации `(rating < 1.0) | (rating > 5.0)`.

3. **Отрицательное количество отзывов (`reviews_count < 0`):**
   * **Где:** Строка 61 (`c_001116`, ООО «Вектор Про»).
   * **В чём суть:** Значение `reviews_count = -10`. Счетчик отзывов не может быть отрицательным.
   * **Как обнаружено:** Проверкой `reviews_count < 0`.

4. **Дробное число отзывов (Float reviews_count):**
   * **Где:** Строка 98 (`c_001079`).
   * **В чём суть:** Значение `reviews_count = 45.5`. Количество отзывов должно быть целым числом.
   * **Как обнаружено:** Проверкой `reviews_count % 1 != 0`.

5. **Битая кодировка / некорректный символ в количестве отзывов:**
   * **Где:** Строка 200 (`c_001187`).
   * **В чём суть:** Поле `reviews_count` содержит битый символ (`'½'` / `\xbd`).
   * **Как обнаружено:** Ошибкой конвертации строки в число `ValueError`.

6. **Повреждённые форматы номеров телефонов:**
   * **Где:**
     * Строка 28 (`c_001004`): содержит буквенные символы `'8 (925) abc-12-34'`.
     * Строка 199 (`c_001091`): неполный номер `'+7'`.
   * **Как обнаружено:** Регулярным выражением `^\+7\s\(\d{3}\)\s\d{3}-\d{2}-\d{2}$`.

7. **Повреждённые ссылки на сайты (`site`):**
   * **Где:**
     * Строка 130 (`c_001064`): содержит битые кириллические символы.
     * Строка 141 (`c_001020`): Опечатка в схеме протокола `'htp://sintez-service-453.ru'` (пропущена буква `t` в `http`).
   * **Как обнаружено:** Проверкой наличия валидной схемы `http://` или `https://`.

## 🧠 4. Логические противоречия (Logical Inconsistencies)

* **Отсутствие рейтинга при наличии отзывов:**
  * **Где:** 14 записей (`c_001083`, `c_001190`, `c_001098`, `c_001180`, `c_001045` и др.).
  * **В чём суть:** Поле `reviews_count > 0` (например, 58 отзывов у `c_001083`), однако поле `rating` равно `NULL`.
  * **Как обнаружено:** Составным условием `reviews_count > 0 AND rating IS NULL`.
